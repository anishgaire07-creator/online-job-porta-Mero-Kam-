# Mero Kam — Job Portal

Full-stack job portal for XAMPP: React (Vite + Tailwind) frontend, PHP 8+ REST API, MySQL database.

## Requirements
- XAMPP (Apache + MySQL + PHP 8+)
- Node.js 18+
- Browser

## Database
- Import `database/mero_kam.sql` into phpMyAdmin
- Default: root / no password

## Backend
- Path: `/backend/api/`
- Apache must be running

## Frontend
```bash
cd frontend
npm install
npm run build
